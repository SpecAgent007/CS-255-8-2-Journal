# CS-255-8-2-Journal

For the DriverPass project, the client required a web based system designed to manage driving reservations, online classes, and practice tests to help customers successfully prepare for their DMV exams. I feel I performed particularly well in developing the UML diagrams, which mapped out system flows like customer booking and test scoring. If I could revise one part of my documentation, I would expand on the technical requirements to detail the security tools necessary for protecting sensitive payment data. Throughout the design phase, I interpreted the user's needs by focusing heavily on creating a seamless, accessible scheduling and testing interface, centering these needs is critical because software only holds value if end users can navigate it efficiently to solve their problems. Moving forward, my approach to software design will rely on visual modeling and thorough requirements analysis to ensure all business logic and user constraints are understood before any coding begins.
